⚡ 快速開關
📖 第一次設定怎麼做(3 步)
  1. 開 OBS Studio(沒裝 → 下載)
  2. 上方選單 Tools / 工具 → WebSocket Server Settings → 勾 Enable WebSocket Server → 點 Show Connect Info → 複製 Server Password
  3. 把密碼貼到下方 Password 欄 → 點「儲存 + 重連」
⚠ 注意:「隱藏」audio source(眼睛 icon)不是「靜音」。靜音才會觸發 — 點 input 旁邊的喇叭 icon 才對。

🎙️ AI 歌聲教練
說明

按「開始」錄清唱、唱到想停(例如唱完一段副歌)再按「停止並送出」→ AI 聽 → 只評這一次(不跟上次比,避免亂掰)
只在你送出才上傳,聽完即丟、不保存音檔;上限 2 分鐘
想讓回饋出現在直播畫面:開控制中心的「🎙️ 教練上字幕」

📖 讓 AI 角色變成會動的 VTuber(4 步)
  1. 開 VTube Studio → 設定 → 啟用 API(預設 port 8001)
  2. 下方勾「啟用」→ 點「連線 / 授權」→ 回 VTS 按「允許」那個外掛視窗
  3. 在 VTS 幫常用表情各設一個快捷鍵(Hotkey),把名稱填到下面對應的情緒
  4. 嘴型:把模型嘴巴的 InputParameter 綁到 MouthOpen 或自建的 CharaCastMouth
需要先在「進階 / TTS」啟用語音,嘴型才會跟著動(用 TTS 音訊驅動)。
連線授權後會自動讀取你模型的表情,並依名稱自動配對。

🖼️ 讓 AI 看畫面(場景感知)
說明

需 OBS 已連線。這台會定時截「目前場景」用 GPU 本地判斷畫面在幹嘛(團戰/聊天/唱歌…)
只把短描述當脈絡送上雲,不傳畫面圖檔

開啟後,還需後台「🧠 AI 感知」也開「看得到畫面」+ OBS 已連線才會上工
🎯 校準這款遊戲(進階,選用)
說明

教 AI 認這款遊戲「每次長得都很像的大事件畫面」(勝利 / 結算 / 死亡 / 五殺…自己命名)
自由新增場景 → 每個場景按「＋擷取」存幾張(多角度更準)
⚠ 行為(團戰 / 走位)few-shot 抓不準,那種改用下面的「框選區」
離線也能校:用別人的畫面 / VOD,自己填遊戲名即可

　
🎯 框選區（戰鬥 / 戰況 / 人頭比數）
說明

在畫面上框要盯的區塊，每框選一種偵測法：
• 變化率（戰鬥框 / 戰況框）— 盯那塊變多快，爆動 = 激戰，不看內容、不受地圖影響
• 讀數字（人頭比數 / KDA）— 讀那塊的數字念給 AI，只送文字
⚠ 讀數字需 HUD 數字夠清楚，版位固定的計分板最準；準度因遊戲而異

尚未框選任何區域
大部分人不用動。除非用自架 cloud / staging。
瀏覽器政策:首次需點一下才允許播音
